# Dataville: Circuit Lab ⚡

A browser-based data engineering architecture learning simulator.

## Play

Open `index.html` in a browser. No build tools, accounts, or services are required.

## Publish with GitHub Pages

1. Create a public GitHub repository named `dataville-circuit-lab`.
2. Upload `index.html` and `README.md` to the repository root on the `main` branch.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Once GitHub finishes publishing, visit `https://YOUR-USERNAME.github.io/dataville-circuit-lab/`.

## Current features

- Three fictional architecture briefs
- Pipeline component selection and compatibility diagnostics
- Autowire example and power-on checks
- Fictional data scanned versus query cost simulation
- Copyable or printable consultant decision brief

## Simulation disclaimer

All client cases and cost outputs are educational and illustrative. They are not production deployment advice or cloud pricing quotations.
